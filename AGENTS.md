# Agent instructions

This repository is **LaTeX to Word** (folder name `math-to-word`).

**Before changing product, architecture, billing, or UI, read:**

1. [docs/saas/README.md](docs/saas/README.md) — index for the paid product and living docs
2. [docs/saas/CURRENT-PRODUCT.md](docs/saas/CURRENT-PRODUCT.md) — what the **free, live app** actually does today
3. [docs/saas/ARCHITECTURE.md](docs/saas/ARCHITECTURE.md) — planned SaaS split (browser conversion vs accounts/billing)

Do not send pasted document content to a server unless the user explicitly changes the privacy model. Conversion stays in the browser unless a later decision document says otherwise.

Do not use KaTeX or Temml. Do not introduce React/Vue/Svelte for the converter unless a decision document records that change.
